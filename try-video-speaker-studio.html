PROJECT LAB / HANDS-ON TESTING

Try Video Speaker Studio.

Transcribe a video, detect speakers, correct their names, join fragmented dialogue, and export subtitles. Follow all the tests or share a link that highlights particular features.

Get the latest release ↗ View GitHub README ↗

Local application, not a cloud demo. The portfolio shows this guide; the video is processed on the person's computer after installation. Please use a recording you have permission to process.

01 / SETUP

Start with a short video

1

Install 64-bit Python 3.11 and FFmpeg; verify ffmpeg -version works in a new terminal.

2

Download and extract the latest app ZIP. Run setup_windows.bat (once) and then run_windows.bat. If you already use a supported Python environment, follow the README's existing-venv instructions instead.

3

Open http://127.0.0.1:5050 on the same computer running the app. Upload a 30–90 second video with two distinct voices, if available. Initial model downloads require an internet connection.

For a first run, select Small, Auto GPU/CPU, and Detect multiple speakers. On Windows, use Chrome or Edge to view the synchronized player and transcript.

02 / HANDS-ON TESTS

What to try

When opened from a focused invitation, only the requested tests appear initially. Check a task after completing it. You can also choose the features to include in a new link.

01

Transcribe a clip with two speakers. Confirm that the transcript identifies separate voices as Speaker 1 and Speaker 2. Listen for any speaker switches or misattributed lines.

02

In the Speakers panel, change Speaker 1 to Alex and Speaker 2 to Jordan (or any labels). Verify that their names update in the transcript and export. If one line is assigned incorrectly, fix it using that line's speaker selector.

03

Find two or more consecutive lines by the same speaker, check their Merge boxes, then click Merge selected lines. Verify that they become one editable sentence with the original starting and ending video times. Keep a copy before merging; there is currently no Undo Merge.

04

Transcribe the same short clip using small and medium. On a capable computer, also try large-v3. Note processing time, words corrected, and whether the model ran on GPU or CPU. Export each run first or re-upload the clip as a separate project to preserve comparisons.

05

Export CSV or JSON with both Video time and Unix milliseconds selected. Unix time requires the real recording start time with a timezone; don't substitute the file modification date. Also export just a selected time range.

06

Export .srt and .vtt, then try an MP4 with selectable or burned-in subtitles. Check whether captions follow video playback. Subtitles always use video-relative time, not Unix milliseconds.

Complete the checklist as you test the app.

03 / HARDWARE CHECK

Which Whisper model can this PC run?

Official OpenAI Whisper specifications provide approximate VRAM requirements. The app actually uses faster-whisper with quantization, which can require less memory. The estimates are a guide, not a compatibility guarantee.
